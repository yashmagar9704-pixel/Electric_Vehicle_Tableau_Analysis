# Electric Vehicle Data Analysis using Tableau

## Project Overview

This project focuses on analyzing Electric Vehicle (EV) population data using Tableau to understand EV adoption trends, vehicle distribution, manufacturer performance, and electric vehicle market growth.

The interactive Tableau dashboard provides insights into Battery Electric Vehicles (BEVs), Plug-in Hybrid Electric Vehicles (PHEVs), electric driving range, vehicle manufacturers, model years, and Clean Alternative Fuel Vehicle (CAFV) eligibility.

The objective is to transform raw electric vehicle data into meaningful insights through interactive visualizations and key performance indicators (KPIs).

## Project Objectives

- Analyze the overall electric vehicle population.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Identify the top 10 electric vehicle manufacturers.
- Analyze EV adoption trends across different model years.
- Evaluate the average electric driving range.
- Understand CAFV eligibility distribution.
- Analyze electric vehicle distribution across different states and locations.
- Identify market trends to support data-driven decision-making.

## Key Performance Indicators (KPIs)

- Total Electric Vehicles
- Total BEV Vehicles
- Total PHEV Vehicles
- Average Electric Range
- BEV Percentage
- PHEV Percentage

## Dashboard Visualizations

- **Top 10 Vehicles by Make:** Identifies leading EV manufacturers based on vehicle population.
- **Total Vehicles by Model:** Compares the number of vehicles across different models.
- **Total Vehicles by Model Year:** Highlights EV adoption trends over time.
- **Vehicles by CAFV Eligibility:** Analyzes vehicle eligibility for clean alternative fuel programs.
- **Vehicles by State:** Displays geographical distribution of electric vehicles.
- **BEV vs. PHEV Analysis:** Compares fully electric and plug-in hybrid vehicle populations.
- **Average Electric Range:** Evaluates the average driving range of electric vehicles.

## Tools & Technologies

- **Tableau:** Data visualization, dashboard development, and interactive reporting.
- **Microsoft Excel / CSV:** Dataset handling and data preparation.
- **Data Analysis:** KPI analysis, trend identification, and business insights.

## Dataset

The dataset contains electric vehicle population information, including:

- VIN (1-10)
- County and City
- State and Postal Code
- Model Year
- Vehicle Make and Model
- Electric Vehicle Type
- CAFV Eligibility
- Electric Range
- Base MSRP
- Electric Utility

This project demonstrates how data analytics and visualization can help understand the growing electric vehicle market. The dashboard provides an overview of EV adoption patterns, manufacturer contributions, vehicle types, and geographical distribution, supporting better data-driven insights into the electric mobility industry.
